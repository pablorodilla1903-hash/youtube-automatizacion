Privacy Policy

Last updated: September 28, 2026

This policy applies to "Timeline Earth Uploader", a private tool used only by the owner of the Timeline Earth YouTube channel to save the channel's own video files to the owner's Google Drive.

Data we access

The tool requests the Google Drive scope drive.file, which only allows it to create and manage the files and folders that the tool itself creates. It cannot see, read or modify any other file in Google Drive.

How the data is used

The access is used exclusively to upload videos, thumbnails and text files produced for the Timeline Earth channel to a folder in the owner's own Google Drive, and to replace or remove older versions of those same files.

Sharing

No data is sold, shared with third parties or used for advertising. The tool is not offered to the public and is only used by the channel owner.

Storage and security

Access credentials are stored encrypted as private secrets and are never published. The owner can revoke access at any time from Google Account permissions.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
