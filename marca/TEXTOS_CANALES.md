## Configuración igual para los dos canales

**YouTube Studio → Configuración (⚙️ abajo a la izquierda):**

1. **General** → Moneda: EUR.
2. **Canal → Información básica** → País de residencia: **España**. Palabras clave: las de arriba.
3. **Canal → Configuración avanzada** → Público: **"No, establecer este canal como no dirigido a niños"**. ⚠️ Es muy importante: si el canal se marca como dirigido a niños, apenas cobra por los anuncios.
4. **Subida predeterminada** → pestaña *Información básica*:
   - Visibilidad: **Privado**, para revisar cada vídeo antes de programarlo.
   - Etiquetas: las palabras clave de arriba.
   - Descripción:
     - Inglés: `Subscribe for a new business story every day 👉 @FortuneFiles`
     - Español: `Suscríbete para una nueva historia cada día 👉 @ExpedienteFortuna`
5. **Subida predeterminada** → pestaña *Configuración avanzada*:
   - Categoría: **Educación**.
   - Idioma del vídeo: **Inglés** o **Español** según el canal.
   - Comentarios: **Activados**. Retener los comentarios potencialmente inapropiados para revisarlos.
6. **Personalización → Marca** → Marca de agua del vídeo: sube `marca_de_agua_150x150.png` y elige **"Al final del vídeo"**.
